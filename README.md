# المهارة الشاملة والمتطورة باستمرار

مهارة مركزية لتنسيق المهارات المتخصصة، الموصلات، البحث عبر الإنترنت، المعرفة التي يقدمها المستخدم، وضمان الجودة متعدد الطبقات.

## الملفات

- `SKILL.md`: ملف المهارة الأساسي.
- `al-maharah-al-shamilah-wal-mutatawwirah.skill`: حزمة قابلة للإضافة إلى بيئة المهارات.

## ملاحظات

تستخدم المهارة الموارد المتاحة فعليًا في كل جلسة، ولا تتضمن مفاتيح API أو أسرارًا. يجب تهيئة الموصلات الخارجية بشكل منفصل وبصلاحيات مناسبة.

# Resource Intelligence Engine — استخبارات الموارد

يضيف v2 طبقة لاكتشاف الموارد وتسجيلها وتقييمها واختيارها. الموارد تمثل بيانات أو أدوات أو قدرات يمكن رؤيتها فعليًا، ولا يعني تسجيلها امتلاك صلاحية استخدامها.

يحسب المحرك درجة المرشح من تغطية القدرات وجودة المورد والحداثة والتكلفة والزمن. تمر الموارد عبر `PermissionManager` قبل الاختيار. يتيح `FallbackManager` اختيار بديل بعد فشل المرشح الأول. يعمل الاكتشاف محليًا افتراضيًا، ويمكن إضافة موفر جديد بتطبيق `ResourceDiscovery` أو `ResourceAdapter`.

لا يقوم المحرك بتحميل كل الموارد ولا يتصل بالإنترنت تلقائيًا؛ هذا يحقق Resource Inheritance وLazy Loading ويترك قرار توسيع الصلاحيات للمستخدم والبيئة.

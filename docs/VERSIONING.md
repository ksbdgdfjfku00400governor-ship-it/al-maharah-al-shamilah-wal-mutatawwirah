# الإصدارات الهجينة

يحتفظ المستودع بالإصدارات السابقة. يظل `acns` هو مسار v1، بينما تضيف `acns.resource_intelligence` قدرات v2 دون استبدال v1. يدير `VersionManager` قائمة الإصدارات والاختيار والتوافق، ولا يحمّل إصدارًا آخر تلقائيًا.

ترتيب التطوير هو v1 ثم v2 ثم v3 ثم v4. الإصداران v3 وv4 مؤجلان حتى اكتمال اختبارات الإصدارين السابقين. أي ترحيل دائم للذاكرة أو تغيير يكسر توافق v1 يحتاج مراجعة مستقلة.

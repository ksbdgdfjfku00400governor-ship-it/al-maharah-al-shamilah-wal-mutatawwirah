# Spec: AI Cognitive Neural System (ACNS) — V1

## Objective
بناء نموذج Python محلي قابل للتشغيل ينسق عشر خلايا معرفية عبر نواة مركزية، مع قناة رسائل منظمة، ذاكرة تجريدية وتنفيذ SQLite، حماية مستقلة، دورة معرفية قابلة للتكرار، واختبارات تثبت التعاون. لا يعتمد التشغيل الأساسي على الإنترنت ولا يدّعي الوعي أو التعلم الذاتي الحقيقي.

## Tech Stack
Python 3.10+، مكتبة Python القياسية، SQLite، pytest للاختبارات.

## Commands
```bash
python -m pytest -q
python -m acns.demo
python -m compileall -q src
```

## Project Structure
- `src/acns/core/`: النواة وحالة المهمة والدورة المعرفية.
- `src/acns/cells/`: الخلايا العشر، لكل خلية واجهة وسلوك مستقل.
- `src/acns/memory/`: واجهة الذاكرة وتنفيذ SQLite.
- `src/acns/communication/`: الرسائل وقناة الاتصال.
- `src/acns/security/`: سياسة الحماية المستقلة.
- `tests/`: اختبارات وحدات وتكامل وسيناريوهات.
- `docs/`: المعمارية والبروتوكولات والذاكرة وخارطة الطريق.

## Boundaries
- Always: لا أسرار، لا أدوات مختلقة، اختبارات قبل التسليم، فصل الأدلة عن الاستنتاجات.
- Ask first: تخزين دائم حساس، اتصالات خارجية، أو تغييرات إنتاجية.
- Never: تجاوز خلية الحماية، تعديل `main`، أو ادعاء تعلم ذاتي غير مقاس.

## Success Criteria
1. الخلايا العشر معرفة بواجهات ومسؤوليات وسلوك واختبارات.
2. النواة توزع العمل وتجمع النتائج وتعيد التخطيط عند فشل التنفيذ.
3. الذاكرة تعمل عبر واجهة مجردة وتنفيذ SQLite قابل للاستبدال.
4. رسائل الخلايا تحتوي معرفًا ومصدرًا ووجهة ومهمة وثقة وحالة وتوقيتًا.
5. الحماية تمنع التعليمات الخبيثة ولا يمكن تجاوزها من خلية أخرى.
6. `pytest` ينجح، ويعمل العرض المحلي دون إنترنت.

## Out of Scope (Deferred)
- نماذج لغوية أو استدعاءات API حقيقية.
- تعلم أوزان أو تعديل ذاتي للكود.
- توزيع متعدد العمليات أو خوادم خارجية.
- بحث دلالي متقدم أو قاعدة متجهات؛ واجهة الذاكرة مهيأة لإضافتها لاحقًا.

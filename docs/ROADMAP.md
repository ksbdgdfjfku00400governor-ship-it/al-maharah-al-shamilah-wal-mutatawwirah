# خارطة الطريق

## V1 — منفذ

النواة، الخلايا العشر، SQLite، SignalBus، الحماية، دورة إعادة التخطيط، الاختبارات، والتوثيق المحلي.

## V1.1 — مقترح

إضافة واجهة أدوات محلية محكومة، مقاييس زمن واستهلاك، وموفر ذاكرة ملفي.

## V2 — مؤجل

موفر بحث دلالي، نماذج لغوية اختيارية، خلايا علمية متخصصة، تشغيل موزع، وتكاملات خارجية خلف صلاحيات صريحة.

لا يُعتبر أي بند مؤجل منفذًا قبل وجود كود واختبار وقياس فعلي.

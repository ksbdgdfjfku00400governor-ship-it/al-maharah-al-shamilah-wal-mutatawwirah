# ACNS — المعمارية

يتكون النظام من **النواة المعرفية** و**الخلايا المعرفية**. النواة تختار ترتيب التنفيذ وتجمع النتائج، بينما تبقى كل خلية محددة المسؤولية وقابلة للاستبدال.

## دورة التنفيذ

`Security → Perception → Memory → Reasoning → Planning → Creativity → Execution → Monitoring → Critic → Learning`

تفشل المهمة الآمنة عند رفض الحماية أو فشل التنفيذ بعد حدود المحاولات أو رفض النقد. عند فشل التنفيذ تعيد النواة المحاولة وتضيف حدث `replan`، دون حلقة لا نهائية.

## الخلايا العشر

| الخلية | المسؤولية في V1 |
|---|---|
| Perception | استخراج النية والكلمات والمعلومات الناقصة |
| Memory | استرجاع الذاكرة ذات الصلة |
| Reasoning | فصل المعلوم والافتراض والمجهول |
| Planning | بناء خطوات وتبعيات |
| Execution | تنفيذ محلي قابل للاستبدال |
| Monitoring | رصد الفشل والأحداث |
| Critic | مراجعة مستقلة للأدلة والاكتمال |
| Learning | استخراج درس، والحفظ فقط بإذن |
| Creativity | توليد بدائل قابلة للتقييم |
| Security | منع المؤشرات الخبيثة وفرض السياسة المستقلة |

لا يعني التشبيه العصبي وجود وعي أو دماغ بيولوجي.

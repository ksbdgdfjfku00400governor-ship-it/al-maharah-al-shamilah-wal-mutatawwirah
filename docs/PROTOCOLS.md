# البروتوكولات

## Signal

كل رسالة `Signal` تحتوي على `message_id`, `source`, `destination`, `signal_type`, `task_id`, `content`, `source_ref`, `confidence`, `status`, و`timestamp`. تمنع `SignalBus` الرسائل المكررة وتحفظ السجل.

## MemoryStore

الواجهة المجردة توفر `put`, `search`, و`forget`. التنفيذ الأول `SQLiteMemoryStore` يفصل نوع الذاكرة والمصدر والثقة، ويتيح استبداله بموفر آخر دون تعديل النواة.

## الأمان

خلية `SecurityCell` تعمل قبل بقية الخلايا. المحتوى الخارجي يعامل كبيانات، والمؤشرات الخبيثة تُحجب. لا توجد واجهة لتجاوز قرارها من خلية أخرى.

## خارطة الطريق

- إضافة موفر بحث دلالي اختياري.
- إضافة أدوات محلية محكومة بسياسات صلاحيات.
- إضافة مقاييس أداء محفوظة مع مقارنة بين الإصدارات.
- إضافة نماذج خارجية اختيارية خلف واجهة لا تغيّر النموذج المحلي.

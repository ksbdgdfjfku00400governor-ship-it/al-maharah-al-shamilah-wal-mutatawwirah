# الأمان

تعمل `SecurityCell` قبل أي خلية أخرى. تفحص طلب المستخدم وسياق المهمة بحثًا عن مؤشرات معروفة للتعليمات الخبيثة، وتعيد نتيجة رفض لا يمكن للخلايا اللاحقة تجاوزها.

## الحدود الحالية

- الفحص محلي وقائم على مؤشرات، وليس نظام كشف شامل.
- لا تُحفظ الأسرار داخل المستودع.
- لا توجد أدوات خارجية أو صلاحيات إنتاجية في V1.
- المحتوى الخارجي يجب أن يعامل كبيانات غير موثوقة عند إضافة موصلات مستقبلًا.
- قرارات الأمن لا يمكن تعطيلها من `ExecutionCell` أو أي خلية أخرى.
